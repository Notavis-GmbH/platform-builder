# Platform Builder

## Install
```shell
wget -O selfInstaller.sh https://raw.githubusercontent.com/Notavis-GmbH/platform-builder/develop/selfInstaller.sh && bash selfInstaller.sh
```

To install a specific version, pass its git tag as an argument. If omitted, the latest commit on the `develop` branch is used.
```shell
wget -O selfInstaller.sh https://raw.githubusercontent.com/Notavis-GmbH/platform-builder/develop/selfInstaller.sh && bash selfInstaller.sh v1.2.3
```
